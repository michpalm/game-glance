# Library Search runtime contract (2026-11-04)
Read-only inspection via the existing private Steam debugger tunnel; no navigation, installation or settings writes.

- `collectionStore.allAppsCollection.allApps` includes all app types. A record is eligible only with `BIsOwned() === true`; its inspected implementation checks `visible_in_game_list && subscribed_to`. Borrowed/shared available library entries also satisfy this predicate. Apply game/demo/shortcut types 1/8/1073741824 and `collectionStore.BIsHidden(appid)` exclusion independently.
- Readiness is `appStore.m_bIsInitialized === true`, set after a complete overview update. The hidden collection must exist. Empty ready arrays are a valid empty library.
- The existing MobX administration symbol's `values_` map exposes disposable `observe_(callback)` subscriptions for computed allApps/visibleApps, hidden m_rgApps, collection replacement and observable title/membership/installation fields. Its source returns the autorun disposer; callbacks are coalesced to a microtask so the initial update's readiness assignment settles first.
- Native `SteamClient.Apps.RegisterForAppOverviewChanges` returns undefined, not an unregister handle. Search deliberately does not register there; doing so would leave a permanent callback.
- Main-window identity is `SteamUIStore.WindowStore.GamepadUIMainWindowInstance.BrowserWindow.document`. Its `History.location.pathname` supplies the current route and `History.listen(callback)` returns an unlisten function. The history listener's implementation appends a listener and the return removes it.
- Account is `App.m_CurrentUser.strSteamID`; it is not recorded here. Use the existing chrome/account observation and epoch guards, without another account timer.

Private identifiers/titles are excluded from the probe and this record. These are observed internal Steam contracts, guarded at runtime; capability drift produces unavailable Search rather than treating cached store records as owned.
