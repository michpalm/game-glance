Steam rounds the 4:3 viewport to 1441 pixels wide and 32:9 to 541 pixels high. The measurements record the actual sizes. Home's feed and tabs intentionally extend below the viewport while the sheet is lowered; hidden content was not treated as clipping. The raised feed was visually inspected separately.

72 layout captures: all three Home row styles, raised feed, two page layouts, two warning layouts, and screensaver at eight sizes. Reviewed contact sheets; primary page controls and metadata remain inside the viewport. Partial cards at horizontal scrollers' edges are intentional.

The unavailable-game test inserts a clearly labeled synthetic source rendered by Steam's actual invalid-platform renderer. The installed component copies the localized text and platform icon next to Last played, hides the native duplicate, and clears the copy when the source is removed. No real game's compatibility, overview or installation state was changed. There is no genuinely blocked game in the current library, so the reporter's exact installation flow remains unverified.

Screensaver tests enable logo, statistics and status bar together, check artwork and overlay bounds, and then restore preferences. Slide advancement passed; reopening passed at the native 1500 × 845 CSS window size. Steam recreated its screensaver debugger target on reopen, so the harness reconnects before measuring. No source fix for the earlier black screen is claimed: restarting Steam recovered that session before this candidate was installed.

Open/back checks passed at all eight sizes. Opened the page through Home's Info action, waited for the bridge and opening markers to clear, then sent B through Steam's controller dispatcher. All returned Home without a leftover transition copy. Settling took 1,473–1,649 ms in these simulations. The initial fixed 1,400 ms sampling caught the animation still running in six cases; those premature checks are retained in `extra-metrics.json`, alongside the successful settle-aware checks in `navigation-metrics.json`. These are smoke checks, not a frame-time or smoothness benchmark.

After the tests, all persisted settings exactly matched the pre-install backup, including newer-version preferences. Both viewport overrides were cleared, synthetic sources and test globals removed, and the Ally returned to Home. A full Gamescope composition capture is stored as `ally-native-home.png`.
