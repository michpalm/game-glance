# Clean information-card handoff

2026-10-23, ROG Xbox Ally, 3.6.0 development branch.

Michael reported a small information-card pop in Clean mode after the new default growth. The earlier transition fixes were already present. The final correction adapts their coordinate conversion to the fractional canvas produced by growth, rather than adding another settling animation.

## Cause and final change

`startHome` divided the canvas's drawn width by `offsetWidth`. The latter rounds to a whole CSS pixel. The Ally's grown canvas has computed width 1325.5 CSS px, but `offsetWidth` is 1326. Its drawn width is 1499.988037109375. The old inferred scale was 1.1312126976692118, versus 1.1316394093620332 from the fractional width. This put the glass approximately 0.384 CSS px right of the crisp ring, even though both were targeting the same painted edges.

The integer-width assumption dates to `5eadd61` (2026-10-09). Growth in this branch makes the previously whole logical canvas fractional; `19ce89b` establishes the current fixed default growth. This identifies the mechanism exposed by scaling, rather than claiming a historical device bisect.

`measureCanvasScale` now uses the drawn width divided by the fractional computed width. The existing card-edge snapping, separate crisp ring, constant blur, card-origin text layers and measured text settling remain in use. The provisional post-ready glass/border glide from `81dc87c` is removed, along with its dedicated tests. No CSS appearance or transition timing changes are needed.

## Device evidence

Recorded the same Home Info opening twice with Clean and Fit on, using animation-frame bounds and screencast frames. The second opening reused the cached page. Both final bridge measurements show the same glass-minus-crisp-ring error in CSS px:

| Coordinate | Before | Corrected |
| --- | ---: | ---: |
| x | +0.383667 | -0.003052 |
| y | +0.255188 | -0.007263 |
| width | +0.162903 | -0.002960 |
| height | +0.029900 | -0.011589 |

The remaining difference is below 0.012 CSS px. The ring intentionally uses device-snapped painted edges, not the native panel's fractional layout rectangle. The native panel's layout bounds therefore differ from the ring by up to 0.452 CSS px; that difference is not evidence of a painted-edge error. Screenshot strips were inspected across the handoff, and a full Gamescope composition capture confirms the final Clean page.
