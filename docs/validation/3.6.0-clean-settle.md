# Clean information-card handoff

2026-10-23, ROG Xbox Ally, 3.6.0 development build. Source fix `81dc87c`.

Michael reported a small pop around the information card as the Clean page settles, while the normal Game Glance layout looked good. Recorded the opening through Home's Info action, without launching a game, with screencast frames and animation-frame geometry/style measurements.

The transition draws an estimated card derived from text measurements, then hands over to a real flex card. The latter has slightly different fractional bounds at the Ally's 1.28 device-pixel ratio. Original final glass offset versus live card: x +0.6400 CSS px, y +0.0538, width -0.2888, height +0.0421. Original crisp border: x +0.2563, y -0.2014, width -0.4517, height +0.0122. The glass is in Home's scaled canvas while the crisp border sits outside it. Text twins already have a measured settling step; the card's glass/border did not.

At page readiness, Clean's bridge now glides both glass and border to the live card's measured bounds over the existing 150 ms settling interval. Canvas and unscaled coordinates are converted separately. Only small corrections up to six CSS px are accepted; hidden/missing panels and invalid scales are ignored. This acts only on the disposable bridge and only for Clean mode. The normal layout and initial morph estimates are unchanged.
