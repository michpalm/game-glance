## Reproduced cause

The installed initial candidate (`29a9723f708b7c2e3c6b21d3747e0992b6c65f12dd9ecdcd956e292347b21a23`) used the destination page's `--gg-d` for the moving normal cards' label/value fonts. That variable was absent on Home. Live frame measurements showed both fonts initially computed as 16px, changing to label 9.49739px and value 25.902px when the page stylesheet arrived. The previously captured settled card bounds could not detect this animation regression.

An isolated temporary stylesheet using the moving grid's own `--gho-x-d` kept both font sizes constant across page loading. Diagnostic CSS was removed afterward. The local correction routes all shared normal-card typography through the supplied unit function. Reintroducing the faulty global unit made the regression test fail; the corrected unit passes.
