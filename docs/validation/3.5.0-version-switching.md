# Version switching validation

2026-10-22, branch based on 8dcc2ac.

## Installer contract

Ally SSH read confirmed `/tmp/_MEI*/decky_loader-3.3.0.dist-info/METADATA` identifies Decky 3.3.0. The installed loader is a frozen executable, without readable Python installer sources. Contract checked against the matching official tag:
https://github.com/SteamDeckHomebrew/decky-loader/blob/v3.3.0/backend/decky_loader/browser.py

`PluginInstallType`: update=2, downgrade=3. `request_plugin_install` stores the selected URL/version/hash and emits a confirmation prompt. Only `confirm_plugin_install` calls `_install`; cancellation drops the pending request. The checksum is checked by `_unzip_to_plugin_dir`. An accepted router call is not proof of installation.

The new picker uses downgrade=3 when selected is older, update=2 when newer, and does not reinstall the same version. Original latest-update behavior remains.
