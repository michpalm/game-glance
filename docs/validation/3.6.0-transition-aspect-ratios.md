## Clean checks

Each case opens through Home's Info action and waits for the page to settle. The harness records the moving pill overlap and the shared card while the native page is available, then captures the settled page and an opaque frozen bridge for pixel comparison. It verifies the same route and content, matching card bounds, card/pill containment, and transition cleanup. Actual settled screenshots/contact sheet were visually reviewed.

- All 16 Clean cases passed.
- Maximum final card x/y/width/height discrepancy: **0.012207 CSS px** (the discrepancy is vertical; width and height match).
- Maximum store-pill vertical separation during visible overlap: **0.007324 CSS px**.
- Bright value-text ink bounding rectangles match in **16/16** pairs: no measured change in their overall pixel extents at handoff.
- Maximum mean absolute RGB difference over bright text pixels: **0.257637** on the 0..255 channel scale. The diagnostic threshold is 5; all cases are well below it.
- Whole-panel average RGB differences ranged from 0.0765 to 1.4237, including backdrop/edge raster differences; this is not treated as proof of a text-size change.
- No card or store-pill clipping, changed content, leftover bridge or opening marker was detected.

Bright ink is defined as all RGB channels above 180, measured over the union of the native/bridge masks inside the card. This primarily checks white values. The full-panel comparison includes labels and bars, while shared content and layout checks cover their structure and geometry. Pixel diagnostics and static screenshot review complement the native-display subjective acceptance; they do not prove that every animation frame is identical on every GPU.
