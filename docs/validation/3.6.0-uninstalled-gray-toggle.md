# Optional gray treatment for uninstalled Home games

2026-10-25. Added **Gray out uninstalled games** immediately below Games row style in Spotlight Home settings. It is enabled by default, preserving the existing appearance for older settings. With Spotlight Home off, the new subordinate control is hidden with the other Home settings.

The persisted boolean `homeGrayUninstalled` controls the uninstalled-game class for both normal cards and loop previews, across Steam, Spotlight and Minimal layouts. The preview's ordinary ghost styling and the row's usual focus/opacity styling are unchanged. Selected cards stay in color; non-Steam shortcuts are excluded as before.
