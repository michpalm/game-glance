# Fit hero backdrop consistency

2026-10-23. Fix source commit `253eba7`; installed 3.6.0 development build on the ROG Xbox Ally.

Home and the game page both use `blur(42px) saturate(1.25) brightness(.8)` on the same full hero artwork. Steam's game page additionally draws a 192 × 62 blurred placeholder over that fill, under the 1920 × 620 fitted hero. Its opacity remained 1 after the sharp hero loaded, changing the backdrop at the transition. Temporarily hiding it confirmed that it contributes to the difference. This originates in the 3.6 Fit rendering path, which excluded the placeholder from fitting but left it drawn over the custom fill.

The page now hides its native blurred images only after the full hero is complete and has nonzero dimensions. They stay visible for a pending or failed hero. Source mutations and load/error events refresh this state; unload removes the owned variables. Fill and the classic page keep their existing rules. Home's blur remains unchanged.

Both stayed visible because the original fix matched only `img[src*="_blur"]`. The full-size fitted image fades through this extra native canvas in the middle, over our own blurred art fill.
