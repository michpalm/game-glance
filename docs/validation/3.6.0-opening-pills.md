# Store and Family Sharing pill opening transition

2026-10-25. User accepted stability when browsing Home, but reported flicker in both pills and movement of the family pill when opening Metro. Work kept the current 16:9 viewport; no aspect-ratio override or preference handler was used.

## Reproduction

Metro 2033 Redux (286690) has both a store selector and a family-copy selector. The opening used Home's scaled interactive pair, then a separate page-sized pair inside the extras fade, then the native pair. The extras wrapper had a border while the native selectable wrapper was borderless with an inner store button. The family pill anchors to that wrapper, producing a 0.855 CSS px (about two physical pixels at DPR 2.32) discrepancy at handoff. The store text inherited different line heights. Independent Home/extras fades overlapped (example effective opacities 0.784 and 0.572), and the extras ancestor faded both blurred pills. The native page also awaited an already-known store label and initially lacked its known store-selector structure.

## Changes

- Native source labels read the existing synchronous cache on the page's first render.
- Native and transition store pills share `SourcePill`'s selectable wrapper and content. Cached store groups preserve the native selector's appearance before its native action is discovered. The actual action still uses the native selector.
- Shared `sourcePillLook` sets the same line height for Home, the transition and the game page.
- The transition pair lives outside the fading extras container. `preparePillOpen` measures its actual native-layout boxes, positions the pair in page units and independently translates the family pill from its Home position. Translation only: no nonuniform scale or text compression.
- One moving pair replaces the overlapping Home/extras copies. The bridge freezes the same final layout. Undo restores all styles/markers when opening is cancelled; the legacy path remains available if measurement fails.
