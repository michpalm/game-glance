## Implementation decisions

1. Disposable, inspected MobX observable subscriptions are used instead of Steam's native overview registration, which returns no unsubscribe handle. If Steam changes that internal capability, Search becomes unavailable; it must not leave a permanent callback or treat cached store records as library ownership.
2. A focused offscreen result is pinned as one extra absolutely positioned row rather than stretching the continuous render window to its index. This bounds DOM/artwork work; if its assumptions change, scrolling/focus placement needs adjustment.
