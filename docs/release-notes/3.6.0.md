# Game Glance 3.6.0

Built on 3.5.0, with more control over artwork and Home content, a larger default layout, and smoother game-page transitions.

- **Hero art: Fill or Fit.** Fill covers the screen. Fit shows the whole art at the top over a blurred copy, on Home and both game-page layouts, including the opening transition. Steam's extra blurred placeholder is hidden after loading so it does not change the Fit backdrop on the game page.
- **Stable store and Family Sharing pills while browsing.** Known store labels, family-copy counts and store-version groups are available immediately on selection, with local metadata warmed ahead of browsing. Ownership still refreshes when Steam's library changes. Opening a game uses one moving pill pair with the native page's layout, avoiding overlapping fades and a family-pill position jump.
- **Optional gray treatment for uninstalled games.** Keep the current gray appearance, or turn it off to show uninstalled Home cards in color across Steam, Spotlight and Minimal rows.
- **Choose Home feed tabs.** Turn What's new, Friends and Recommended on or off individually. Disabled tabs load no content; turning all off removes the feed. Returning from a game selects an available tab, with focus restored after Quick Access closes.
- **Larger default layout.** Home, game pages, status bar, opening transition and screensaver use a fixed larger default, with adjustments for different screen shapes. This supersedes the earlier experiment that followed Steam's display scale.
- **Smoother Home-to-game transitions.** Clean and normal information cards share the settled page’s layout and styles. Moving text keeps its proportions, borders stay present during loading, and store/Family Sharing pills use one measured pair through the handoff.
- **Clearer settings.** Game logo and Hero art live together under Appearance because they affect both Home and game pages. The Home settings section is named Home page, and the Game Glance page toggle is shortened to Game Glance. With Spotlight Home off, only its main toggle remains visible in the Home page section.

Retains 3.5.0's version switching, settings preservation, Minimal row, controller battery, cloud badges and installation explanations. EmuAchievements remains deferred.

Validation covers the ROG Xbox Ally at its native 16:9 display, the shared Clean transition across eight emulated viewport shapes, normal-layout openings and Back navigation, store/Family Sharing pill stability, and all three games-row styles with gray treatment enabled and disabled. Viewport emulation is not physical testing on eight monitors or Steam Deck hardware.
