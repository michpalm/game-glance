# Game Glance 3.4.2 (pre-release)

A test build for people who use **HLTB for Deck**. It's 3.4.1 plus the fix below. The built-in updater ignores it:
install it from the zip on this release page (Decky → Developer → Install plugin from ZIP). Once it's confirmed, the
updater offers it as usual.

- **The Play row no longer slides under the cards with HLTB for Deck.** A few seconds after a Steam game's page opened,
  HLTB for Deck added its own row of times above Steam's Play row and pushed it down behind Game Glance's cards. On the
  Game Glance page that row is now hidden: Game Glance's HowLongToBeat card already shows the same times. With the
  Game Glance page turned off, HLTB for Deck's row shows on Steam's page as before.

Tested on a ROG Xbox Ally with HLTB for Deck 2.0.12. Thanks to dadzios for the report and the video (#67).
