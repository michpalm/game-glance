# Game Glance 3.4.1

Fixes for the games row, the way into a game's page and play time on Home. Update from Quick Access → Game Glance → Updates.

- **Your recent games in the order Steam's Home shows them.** This is for the Games row set to recent games; a row
  showing a collection is unchanged. Games you played or installed on this device come first. Games you played only on
  another PC or handheld follow later in the row (from the 16th place), as on Steam's Home. A game you played here that
  Steam's servers have not seen yet shows its last played time instead of "Added".
- **Changed your mind? Press B.** Right after you pick a game, B now takes you straight back to Home with Steam's back
  sound and the same fade as coming back from a game page, and A works again at once. Once the game page is up, Steam
  handles B as always.
- **Play time you can trust on Home.** Home's play time now always matches the game page. It could show far more than
  you played (Red Dead Redemption 2: 223 hours on Home, 38 on the game page). Games you added to Steam from Lutris now
  show Lutris's own count, which includes play you started from Lutris.
- **No missed first press.** After coming back from a game page with B, the first Left or Right press always moves the
  selection.
- **No flicker at the top when opening a game.** With Game Glance's status bar turned off, or with the Game Glance
  page turned off (so games open on Steam's own page), Steam's top bar now stays on screen through the opening
  animation instead of disappearing and coming back.
- **A clearer setting.** The Games row style setting now says what Steam and Spotlight do. If your row started to move
  differently after 3.3.0: `Prefer the selected game wide at the left? Quick Access → Game Glance → Spotlight Home → Games row style → Spotlight.`
