# Game Glance 4.0.0-rc.4

## Added since 4.0.0-rc.3

This candidate contains 60 commits made since the previous prerelease on 10 November.

### New pages

- **Library.** A hero, grouped game facts, L1/R1 tabs, and dense cover rows. It also introduces the shared page kit used by the new pages. The Library page remains marked **in progress** and unavailable through the settings toggle for this prerelease.
- **Media.** A gallery grouped by day, viewer and full screen, upload and delete actions, and a **Games** tab that groups local screenshots and recordings by game. Screenshot notifications show the captured shot and open it in Media.
- **Settings home.** A grouped list with collapsible groups, live panels, and a direct jump into Steam’s corresponding page.
- **Downloads.** The active download’s art and logo, with disk and peak-speed graphs.
- **Wi-Fi and Storage.** Game Glance versions of Steam’s Wi-Fi and Storage screens.

### Home and game pages

- **Game information.** Choose three stats and a featured card: ProtonDB, achievements, play time, or HowLongToBeat.
- **Title size and accent colour.** Choose Small, Medium, or Large titles; use a per-game accent or pick your own.
- **Recommended and Friends.** Steam’s Personal Calendar can be the Recommended row with trailers; Friends uses game-first cards and the hero is frosted beneath the feed.
- **Theme music and return.** NonSteamLaunchers theme music has a single ♪ button, and returning from a game page to Home glides smoothly.
- **Layout scale.** Game Glance renders at 88% on TV and 94% on handheld.

### In-game menu

- **Resume.** The game’s art resumes the game, without the white square.
- **Achievements.** A Game Glance Achievements page with Achievement Sets, pins, and sorting.
- **Power and Navigate.** Power returns to Game Glance with confirmation dialogs in its visual style; Navigate follows its new order.
- **Frost.** Support for SDR games on an HDR display. The true-HDR path is included but remains untested.
- **Pills, pickers, and status.** Player-count pills, status and audio pickers, and a controller battery indicator that no longer blinks.

### Menus and input

- **Context menus.** Steam context menus use Game Glance’s frosted style; the menu dims the screen the same way, and the game menu has improved navigation.
- **Screensaver wake.** B is consumed while waking the screensaver, avoiding Steam’s menu opening as part of the same press. Two repeat checks on the PlayStation build returned without opening it.

## Install or roll back

After this prerelease is published, open **Game Glance → General → Choose version**, turn on **Show prereleases**, select **4.0.0-rc.4**, and confirm through Decky. You can also install the attached `game-glance.zip` through Decky's **Install plugin from ZIP**. To return to stable, choose a stable version from the same picker.

For the original 4.0 preview, see [4.0.0-rc.1](https://github.com/michpalm/game-glance/releases/tag/v4.0.0-rc.1). The existing [screenshot issue](https://github.com/ValveSoftware/gamescope/issues/2416) still applies: close the in-game Game Glance menu before taking a Steam screenshot when compositor frost is active.

Please share how the new pages, Media collections, context menus, and controller navigation feel on your device, and report any unexpected focus or return behavior.
