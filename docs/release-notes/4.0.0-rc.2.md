# Game Glance 4.0.0-rc.2

This release candidate fixes the version picker in Steam’s Quick Access menu. The picker keeps your selection when the version dropdown closes, so you can install a test build or switch back to a stable version. Decky asks you to confirm before installing.

For the full 4.0 preview, see the [first release candidate](https://github.com/michpalm/game-glance/releases/tag/v4.0.0-rc.1).
