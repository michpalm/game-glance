# Game Glance 2.1.0

A small release with one job: from now on, Game Glance updates itself from Game Mode.

## Updates
- **Built-in updater.** Quick Access → Game Glance → **Updates** shows the installed version and whether a newer release is out. **Update to …** hands it to Decky's own installer, which asks to confirm, checks the download against GitHub's checksum, installs it and reloads Game Glance. No more Desktop Mode or Developer menu for updates.
- **Check for updates** asks GitHub right away.
- **A quiet daily check:** Game Glance looks for a new release when it loads (at most once a day, also across restarts) and every 24 hours while it runs. No pop-ups; the answer waits in Quick Access.

Only the release's public details (version and download link) are fetched from api.github.com; nothing about you is sent.

Everything else is 2.0.0 as it was. The next big release (3.0) will arrive through this updater.
