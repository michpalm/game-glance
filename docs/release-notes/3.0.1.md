# Game Glance 3.0.1

A fix for the pre-load. Coming from 3.0.0 or 2.1, update from Quick Access → Game Glance → Updates.

- **Pre-load game info no longer gets stuck.** If a game's request never answered, the pre-load could wait on it forever
  ("Stop (0 / 55)") and Stop did nothing. Now a game that takes too long is skipped and the run carries on, and Stop
  ends the run at once.
- **HowLongToBeat never waits forever.** The game page's card and Home's chips give up after 20 seconds and try again
  next time; a game keeps the times it already had.
