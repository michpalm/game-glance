# Game Glance 3.0.2

Two small fixes. Coming from 3.0.x or 2.1, update from Quick Access → Game Glance → Updates.

- **A sound for every game you switch to.** On Home, L1 and R1 now play Steam's tab sound for each game they step to,
  and Left and Right on the game cards play Steam's usual move sound, also while held. Switching games used to be
  silent.
- **The clock follows Steam's 24-hour setting again.** The status bar on Home and the game page shows 12 or 24 hours
  as set in Steam's Settings → System. On current Steam it always followed the language's default instead.
