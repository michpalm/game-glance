# Game Glance 4.0.0-rc.3

This release candidate improves Library Search and the Compact keyboard, restores menu blur over Steam Home on Anatase, and makes several menu controls more responsive.

- **Anatase Home frost.** The Steam Home menu can blur even when Gamescope and Steam omit HDR feedback. This was verified on an Anatase Steam Deck, handheld and docked. The in-game Gamescope blur still has its existing SDR requirements. [Issue #80](https://github.com/michpalm/game-glance/issues/80)
- **Compact keyboard.** Library Search uses the same Compact size as Social. The D-pad moves between keys and A selects the highlighted key. Hold A on the move strip and use the D-pad to reposition it. The Search keyboard is frosted when parked and suspends blur while moving.
- **Compact shortcuts.** Y inserts a space, X deletes, L2 shifts, R2 finishes, and L1/R1 move the text cursor. B closes the keyboard.
- **Library Search.** A brighter highlight with an inset outline makes the focused result easier to see. Closing Search clears the query and scroll position. Going back from results to edit keeps the query for that search.
- **Live sliders.** Quick Settings sends volume, microphone and brightness changes as the slider emits values. Performance does the same for frame limit. Writes are rate-limited during continuous input.
- **Spotlight Home.** B on the game row stays on Home. Under **Status bar → Profile style**, choose a presence **Dot** inside the status pill, or a **Circle** or **Square** avatar.

## Install or roll back

In **Quick Access → Game Glance → Updates → Choose version**, enable **Show prereleases**, select **4.0.0-rc.3**, and confirm through Decky. You can also install the attached `game-glance.zip` through Decky's **Install plugin from ZIP**. To roll back, choose a stable version from the same picker.

See the [first 4.0 prerelease](https://github.com/michpalm/game-glance/releases/tag/v4.0.0-rc.1) for the full feature overview and the known in-game screenshot issue.
