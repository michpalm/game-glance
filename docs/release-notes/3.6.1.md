# Game Glance 3.6.1

This stable update adds an optional prerelease picker. Open **Game Glance → General → Choose version → Show prereleases** to see published test builds. Each test build is labelled **prerelease**, and Decky asks before installing it.

Automatic update checks continue to offer stable releases. If you try a prerelease and want to switch back, open **Choose version**, select a stable version, and confirm the downgrade in Decky.
