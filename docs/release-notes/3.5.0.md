# Game Glance 3.5.0

A stable return point for future updates, with version switching, a new games-row style and status-bar polish.

- **Choose a version.** Install any published stable release from 3.5.0 onward through Decky's confirmation flow, including returning to an older version. Settings preserve preferences introduced by newer versions when an older version saves them.
- **Minimal games row.** All game cards stay at the small portrait size, with Steam-style scrolling. Steam and Spotlight remain available.
- **Bluetooth controller battery.** Supported connected controllers show their reported battery percentage in the status bar, separately from the handheld battery.
- **Cloud status.** A white cloud with a small state badge matches between Home and the game page, including the opening transition (#64).
- **Installation explanations.** Steam's unavailable-game messages, such as "Available for Windows", remain visible. On the restyled page they appear next to Last played; the classic layout keeps Steam's message below the main button (#62). Installation and compatibility restrictions remain controlled by Steam.
- **Less unused artwork work.** Minimal skips the wide-card artwork warm-up, and failed artwork copies are released.

EmuAchievements integration remains deferred.
