# Home Feed Tabs On and Off Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A switch for each of Home's feed tabs (What's new, Friends, Recommended); a tab that is off is not shown and loads nothing, all off removes the feed, and Quick Access shows a row only while the row it depends on is on.

**Architecture:** One pure module (`home/feedTabs.ts`) owns the tab ids, the setting's shape and the shown-tab decisions. `FeedSheet` selects its tab by id from the shown list it is given; `SpotlightHome` drops the sheet, its mouse toggle and the raise when nothing is shown; `useHomeData` passes each tab's switch as the existing hooks' `enabled`. The settings panel's rows come from a pure, ordered visibility list (`components/settingsRows.ts`).

**Tech Stack:** TypeScript, React (Decky, `@decky/ui`), Vitest.

**Spec:** `docs/superpowers/specs/2026-10-23-feed-tabs-design.md`

## Global Constraints

- `Settings.feedTabs: { news: boolean; friends: boolean; recommended: boolean }`, default all `true`; each field read on its own (a missing or non-boolean field takes its default).
- Tab order: What's new (`news`), Friends (`friends`), Recommended (`recommended`).
- Copy: **What's new** — "News and events from your games, and recently updated games." **Friends** — "What your friends are playing, and what is trending among them." **Recommended** — "Games from your library to play next." Show wishlist deals keeps its text.
- Quick Access order, Spotlight Home section: Spotlight Home; [Games row; Sort by (collection only); Games row style; What's new; Friends; Recommended; [Show wishlist deals]]; Status bar; [Profile picture in the status bar]; Game logo; Hero art. Brackets: shown only while the row before the bracket is on. No extra visual indent (the panel's existing pattern, as Clean look).
- L1/R1 stay clamped at the ends, no wrap.
- Home memory is session-only (`homeMemory`, never on disk): changing `HomeMemory.tab` to an id needs no migration.
- Commits use the noreply identity copied from `git log -1 --format='%an <%ae>'` (author and committer); no push. Ask before installing on the Ally.

## Review Focus

1. A switch changed while Home is open behind Quick Access with the feed raised on that tab: the first shown tab is selected and focused; never a blank sheet or focus lost. (Task 2 test `nextTabId`.)
2. All three off while focus is in the feed: focus returns to the game cards, the page lowers. (Task 2 test `nextTabId` returns null; Task 2 Step 6 wiring.)
3. A restore whose remembered tab is now off: first shown tab, remembered card dropped. (Task 2 test `restoreTabId`.)
4. Recommended off with Show wishlist deals on: no store request, no Steam ID read. (Task 3; Ally network check in Task 5.)
5. Stored settings from an older or newer version (`feedTabs` missing, partial, an array, a string): each field falls back on its own, other stored settings are kept. (Task 1 tests.)

- [ ] **Step 3: Implement `restoreTabId`, `nextTabId` and `HomeMemory.tab: FeedTab | null`**

- [ ] **Step 4: `FeedSheet` selects by id from `tabs`**

- The strip is `TABS.filter((t) => tabs.includes(t.id))`; every index (`tabRefs`, `tabForButton(index, button, shown.length)`, `shoulderSound`, `gh-tab-on`) is into that filtered list.
- State holds the id: `useState<FeedTab>(() => restoreTabId(restore?.tab, tabs) ?? tabs[0])`; the index is `shown.findIndex(t => t.id === tabId)`.
- An effect on `tabs`: when `nextTabId(tabId, tabs)` differs from `tabId`, select it, reset the selected cards (`at`, `row`) and, when focus is in the tabs or feed (`raised`), focus the new tab.
- A restore whose remembered tab is not the restored one (`restoreTabId` fell back) uses `feedKey: null`.
- `noteHome({ tab: tabId, feedKey })`.

- [ ] **Step 5: `SpotlightHome` without a feed**

`const shown = shownTabs(feedTabs)` (from `useSettings()`). With `shown.length === 0`: no `<FeedSheet>`, no `.gh-sheet-toggle`, `raiseSheet` returns at once (covers the swipe up), and if `zone` is `'tabs'` or `'feed'` an effect calls `focusGames()` (Review Focus 2). Otherwise `<FeedSheet tabs={shown} …>`.
