# Follow Steam's Display Scale Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Home, the restyled game page, the status bar, the open transition and the screensaver grow with Steam's display scale above 100% (never shrinking below today's look), and Home's stack gives way in the approved order when the larger size leaves too little room.

**Architecture:** One pure growth factor `g = clamp(devicePixelRatio, 1, cap)` multiplies today's canvas scale and divides its logical size (`home/scale.ts`); every caller passes its window's pixel ratio. The page's CSS unit multiplies by the same `g` through a `--gg-grow` variable. A pure `giveWay()` (`home/giveWay.ts`) turns the room missing on a shorter canvas into the four steps, applied as CSS variables on Home's root; the stack moves up by the room it needs and the title block keeps its bottom.

**Tech Stack:** TypeScript, React (Decky), CSS-in-TS (`homeCss.ts`, `themeCss.ts`), Vitest.

**Spec:** `docs/superpowers/specs/2026-10-23-ui-scale-design.md`

## Global Constraints

- Growth `g = max(1, f)` where `f` is the `devicePixelRatio` of the window the element is drawn in (`ownerDocument.defaultView`, never the plugin's global `window`); a missing, zero or non-finite `f` counts as 1. Capped at `g ≤ baseLogicalHeight / MIN_LOGICAL_HEIGHT`.
- At `f ≤ 1` every function returns exactly what it returns today (existing tests stay green unchanged).
- Give-way order and amounts (logical px): 1 air above the title, 118 → 66 (52 Steam top bar + 14), up to 52; 2 title slot two lines → one (58); 3 gaps inside the title block: `TITLE_BLOCK.gap` 18 → 12 (3 gaps: 18) and `actionsMargin` 8 → 1 (7), 25 in all, all at once; 4 stats chips hidden (`chipRow` 69 + one gap 18 = 87). Total 222.
- Never give way: games row, action row, store pill, tab strip, Steam's legend reserve.
- A title too long for one line in step 2 shrinks its font to fit (never cut); a logo is drawn to the one-line height (58).
- Commits use the noreply identity copied from `git log -1 --format='%an <%ae>'` (author and committer); no push. Ask before installing on the Ally; Steam's display scale is changed on the Ally only through `SteamClient.Window.SetGamepadUIManualDisplayScaleFactor` and restored to Michael's `1.1951956748962402` after.

## Review Focus

1. A pixel ratio that changes while Home or a page is open (Michael changes Steam's scale): Home, the page and the status bar follow on the next resize without remounting. (Task 3: callers read `f` with the size they already follow.)
2. The open transition at a grown scale: Home's and the page's sizes stay equal, so the hand-over shows no jump (Task 3 `pageDUnit` = Home's scale test; Ally recording in Task 5).
3. A long two-line title once step 2 applies: it shrinks to one line, never clipped mid-word or overlapping the eyebrow (Task 4 CSS; Ally check with a long title in Task 5).
4. Home without a game (the empty Library row) and with the feed raised at a grown scale: nothing overlaps Steam's legend or the status bar (Task 4 `giveWay` tests on the feedless and raised shifts; Ally check).
5. A docked TV or 21:9 screen at Steam 100%: no growth, today's layout (Task 2 test with `f = 1` on 21:9).

### Task 1: The give-way steps

**Files:**
- Create: `src/home/giveWay.ts`
- Test: `tests/home/giveWay.test.ts`

**Interfaces:**
- Produces: `GIVE_WAY = { air: 52, titleLine: 58, gaps: 25, chips: 87 } as const`; `GIVE_WAY_TOTAL = 222`; `STACK_BOTTOM` (the tab strip's bottom plus its clearance: `FEED_SHEET.tabsTop + FEED_SHEET.tabHeight + FEED_SHEET.tabClearance`, 751.6); `MIN_LOGICAL_HEIGHT = Math.ceil(STACK_BOTTOM + FEED_SHEET.legendReserve - GIVE_WAY_TOTAL)` (576); `interface GiveWay { need: number; titleLines: 1 | 2; gapsTight: boolean; chipsHidden: boolean }`; `giveWay(need: number): GiveWay`; `titleGive(g: GiveWay): number` (px the title block frees: `(2 - titleLines) * 58 + (gapsTight ? 25 : 0) + (chipsHidden ? 87 : 0)`); `roomMissing(logicalHeight: number, legendReserve: number): number` (`max(0, ceil(STACK_BOTTOM + legendReserve - logicalHeight))`, 0 for a broken height).
- `giveWay` is pure: `need` (room missing, logical px) is clamped to 0..`GIVE_WAY_TOTAL`; the stack moves up by `need`. The air above the title absorbs the first 52; past that, steps 2, 3 and 4 switch on in order, each whole, as soon as the room they follow is not enough. Whatever the title block frees beyond `need` returns as air above the title (its top is `118 - need + titleGive`).

it('drops the title to one line past the air', () => expect(giveWay(53)).toEqual({ need: 53, titleLines: 1, gapsTight: false, chipsHidden: false }));
it('tightens the gaps past the title line', () => expect(giveWay(111)).toMatchObject({ titleLines: 1, gapsTight: true, chipsHidden: false }));
